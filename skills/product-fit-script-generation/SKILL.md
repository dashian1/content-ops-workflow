# 产品匹配脚本生成

Generate scripts from:

```text
viral analysis
+ product match
+ product library
+ viral template library
```

Required product-fit checks:

- Which product fits best.
- Why it fits this viral structure.
- Where the product naturally appears.
- Which visual proof must be shown.
- Which viral expressions cannot be copied.
- What compliant replacement language should be used.

Generate multiple candidate styles when possible:

- 猎奇
- 反差
- 反反差
- 共鸣
- 避坑
- 教程
- 生活仪式
